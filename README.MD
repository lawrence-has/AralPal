## Project Description
AralPal is a student learning website designed to help students
access learning materials, take quizzes, and monitor their learning
progress. The system aims to provide an accessible and organized
learning experience for students.

The website includes lessons, quizzes, student login, an
administrator dashboard, and student progress tracking.

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Laragon
- Git
- GitHub

## Main Features
- View and read lessons
- Take quizzes and view scores
- Student registration and login
- Administrator dashboard
- Track student learning progress

## Local Development Setup
1. Install and open Laragon.
2. Place the project folder inside `C:\laragon\www\AralPal`.
3. Start Apache and MySQL.
4. Open `http://localhost/AralPal/` in your browser.
